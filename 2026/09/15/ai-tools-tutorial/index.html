Trae · 字节生态

手机号 / 抖音 / 飞书 三通道

Trae 国内版账号体系与字节跳动生态深度绑定。

  • 手机号验证码 — 最基础的登录方式
  • 抖音扫码 — 零成本注册
  • 飞书账号 — 企业用户组织架构同步

Qoder · 阿里云生态

阿里云 / 邮箱 / GitHub 三通道

Qoder 依托阿里云账号体系，覆盖个人和企业两类场景。

  • 阿里云账号 — 企业用户入口
  • 邮箱注册 — 个人开发者快速开箱
  • GitHub 快捷登录 — 海外/开源友好
  • RAM 子账号 — 企业级细粒度权限管控
一句话：阿里云账号一站式打通百炼大模型平台、企业知识库、云资源管理。四端共享同一套 Credits 配额。

Code as Design · 谁在填补设计→代码的鸿沟？

TraeWork Design 模式 — 设计稿 + 图片编辑 + 代码生成

TraeWork Design 模式支持设计稿生成、图片编辑与一键转代码。

  • 设计稿生成 — 自然语言 → 设计稿
  • 自然语言批量修改 — 选中元素文字提意见
  • 设计系统管理 — 组件级复用
  • 设计稿转代码 — 直接生成可运行前端代码
定位：编码能力向设计侧的延伸，核心还是围绕代码生成。
Qoder · 设计原生

QoderWork CN · Code as Design — 100+ 风格

设计工作台是独立产品形态，核心理念是 "Code as Design"。

  • 4 个工作台：通用 / 设计 / 写作 / 幻灯片
  • 100+ 设计风格参考：从 Apple 到赛博朋克
  • 多组件库支持：Ant Design / Element Plus / Tailwind
  • 产物一键交付：设计稿 → 工程 → IDE 继续开发
  • 暗黑/亮白模式：实时切换预览
定位：独立的设计工作站，产品/设计/前端共用工具链。
团队协作

工作流编排 · 企业管控 · 审计合规

团队场景是两款产品从"个人工具"升级为"企业平台"的关键能力。

Trae 企业版

TraeWork + 企业控制台 两大协作引擎

  • 人员与席位管理：邀请/批量添加/移除，自动释放席位
  • 数据分析看板：活跃趋势、AI 生成率、模型调用分布
  • 企业文档集：内部知识库规范 AI 输出
  • 企业智能体：专属 AI Agent 编排
  • 审计与日志：管理员操作日志与追溯
  • 安全策略：命令黑名单、IP 白名单（旗舰版）
  • SSO / 共享额度池：旗舰版支持
  • 飞书 MCP 对接：知识库/文档/审批流打通
小结：企业控制台 + TraeWork + 飞书生态，从管理到审计到 IM 协同形成闭环。
Qoder · 阿里云生态

知识库 + Rules + Skills 三大协作基石

  • 企业知识库增强：AI 基于企业标准生成代码
  • Rules 规则引擎：.qoder/rules/ 定义团队编码规范
  • Skills 技能市场：复用第三方技能，团队共享
  • MCP 扩展：连接 GitHub/Figma 等外部服务
  • RAM 权限管理：阿里云 RAM 细粒度角色控制
  • Credits 团队管理：Teams / VPC 订阅统一配额
  • Cloud Agents：全托管 AI Agent 平台，API 调用
  • QoderWork 连接器：钉钉/飞书/微信 IM 集成
小结：Rules + Skills + 知识库形成"规范→执行→复用"闭环，阿里云 RAM 支撑企业管理。

场景推荐

不同场景 该选谁

没有绝对的"更好"，只有"更适合"。

📊
办公自动化 · 文档/PPT/报表
→ 选 WorkBuddy — 腾讯生态深度集成，文档/PPT/表格/周报全自动，SkillHub 8万+技能即取即用。
→ Trae / Qoder — 偏代码场景，办公能力较弱。

终端 / SSH / 远程开发
→ 选 Trae — TraeCode CLI 是终端原生 Code Agent，适合服务器开发、Vim 用户。仅企业旗舰版可用。
→ Qoder — Qoder CN CLI 为独立产品，npm 安装即可使用。
🎨
设计 → 代码 · 快速原型
→ 选 Qoder — QoderWork CN 设计工作台是独有优势：100+ 风格、多组件库、产物一键交付 IDE。
→ Trae — TraeWork Design 模式（支持图片编辑），设计生态快速迭代中。
🤖
全自动端到端交付
→ 选 Trae — TraeWork Code 模式是国内最完整的 Autopilot 实现，从需求到部署全自动。
→ Qoder — Quest/Agent 偏人机协作，强调"可审查性"。
🧩
存量 IDE 用户（VS Code / IDEA）
→ 选 Qoder — Qoder CN 插件直接装在现有 IDE 中，零迁移成本。JetBrains 全家桶尤其适合。
→ Trae — 独立 IDE，虽支持一键导入，但需要安装新应用。
📋
团队协作与工作流
→ 选 Trae — 企业控制台提供完整管理能力 + 飞书 MCP 打通。
→ 选 Qoder — Rules 规则治理 + Skills 复用 + 企业知识库，阿里云 RAM 支撑权限管控。
🏢
企业合规 / 国内部署
二者均适合 — 都支持数据不出境、国内模型。生态选择是关键：飞书/抖音 → Trae，阿里云/钉钉 → Qoder。
🆓
预算敏感 · 个人开发者
→ 选 Trae — 个人免费版可用基础功能，付费速通 Pro ¥59/月起（100次/月）。
→ 选 Qoder — 社区版免费，Pro 59元/月，含 2000 Credits，体验版含 2 周 Pro 试用 + 300 Credits。

⚡

Trae 更适合你，如果：……

你追求"少说话多干活"——TraeWork 端到端交付省心；你是终端重度用户；团队需要正式的管理控制台、审计、安全策略；你用飞书/抖音生态；免费版就能满足日常需求。

最佳场景：全自动交付 · 终端开发 · 企业管控 · 飞书生态 · 低门槛入门
🌐

Qoder 更适合你，如果：……

你已有 VS Code/IDEA 不想换，装个插件就用；工作流包含"设计→代码"的原型环节；喜欢"先出方案再执行"的 Spec 驱动模式；你用阿里云/钉钉生态；团队靠"规则治理"。

最佳场景：办公自动化 · 腾讯生态 · 全场景 AI 助手 · 技能市场 · 非技术岗位

Trae · Chapter 02

国内版核心产品：它们各是什么？

Trae 国内版提供多个产品形态，分别对应命令行开发者、桌面 IDE 用户、以及全自动 Agent 交付。

Product · 01
TraeCode CLI
命令行 AI 编程工具 · Terminal Native

TraeCode CLI 是运行在终端里的 AI 编程代理。无需打开 IDE，Agent 就能读懂代码库、执行任务、生成 PR。适合服务器远程开发、SSH 场景、习惯 Vim/Neovim 的开发者。注意：TraeCode CLI 目前仅企业旗舰版可用。

# Windows (PowerShell) 官方安装
irm https://trae.cn/trae-cli/install.ps1 | iex
# macOS / Linux
sh -c "$(curl -L https://trae.cn/trae-cli/install.sh)"
# 进入项目目录启动
TraeCode CLI
终端原生SSH 友好脚本可编排MCP 支持
Product · 02
TraeCode
桌面 IDE 主程序 · Flagship

TraeCode 是国内版桌面客户端，基于 VS Code 内核，中文界面 + 国产模型 + 内置 Agent 面板。兼容 VS Code 插件生态，一键从 Cursor / VS Code 迁移。

# 官网下载安装：
open https://www.trae.com.cn/download
# 或 winget / brew
winget install ByteDance.Trae

Product · 03
TraeWork
AI 工作平台 · 全自动交付

TraeWork 是 Trae 最核心的 AI 工作平台（原 SOLO 升级）。提供 Work/Code 双模式。Code 模式是"只出一张嘴"模式：需求 → 拆解 → 建仓 → 写码 → 测试 → 修 Bug → 部署全自动。支持三端协同、Design 模式、定时任务。

Trae · Chapter 03

四步上手：从安装到第一个 Agent 任务

以 TraeCode 桌面版 + TraeWork 为例，四步完成你的第一次 AI 辅助编程。

01
下载安装 TraeCode 国内版
INSTALL · 约 5 分钟

访问 trae.com.cn 或 www.trae.com.cn/download 下载对应系统版本（Windows / macOS / Linux）。启动后选择"国内版"，使用手机号 / 抖音 / 飞书任一方式登录。

提示：Trae 支持一键从 VS Code / Cursor 导入设置、插件、快捷键与主题，迁移几乎零成本。
02
选择工作模式：Chat / Builder / Work

常见问题 FAQ

Q01
Trae 国内版和国际版有什么区别？可以互通吗？
两者是独立发行版本，账号体系不互通。国内版使用国产模型、面向国内合规；国际版使用 Claude/GPT/Gemini、面向海外。数据和账号完全独立，需分别注册。安装时根据所选区域确定版本。
Q02
免费版够用吗？速通次数是什么意思？
Trae 个人免费版包含基础 Chat 和 Builder 功能，以及一定的 TraeWork 配额。速通次数是 TraeWork 的调用配额，付费用户有更高的月度额度并享有免排队特权。普通日常开发免费版基本够用，重度用户建议 Pro 及以上。
Q03
TraeWork 生成的代码质量如何？能直接上生产吗？
TraeWork 在常见项目类型（前端应用、工具脚本、API 服务）上表现出色，代码可直接运行。但对于复杂业务逻辑、性能敏感场景、安全要求高的系统，仍需人工 review 和测试。建议作为"超级初级开发者"使用，而非完全替代人类工程师。
Q04
TraeCode CLI 和 TraeCode 有什么关系？都需要装吗？
两者是独立产品。TraeCode 是图形界面的完整开发环境，适合大多数开发者；TraeCode CLI 是命令行工具，适合终端用户和自动化场景。大多数情况下只需要 TraeCode 即可。注意：TraeCode CLI 目前仅企业旗舰版可用。
Q05
企业版和个人版有什么区别？怎么选型？
个人版适合独立开发者和小团队；企业版增加了企业控制台（人员管理、数据分析、审计日志、安全策略、SSO）、企业文档集、企业智能体、飞书 MCP 集成等能力。10 人以上团队或有合规要求的企业建议评估企业版。

Credits 是什么？不同模式怎么消耗？
Credits是 Qoder 的计费单位。不同模式消耗不同：Ask 模式消耗最低（适合日常问答），Agent 模式中等（适合编码任务），Quest 模式消耗较高（适合大型任务但产出也更完整）。社区版有免费额度，Pro 版 59 元/月含 2000 Credits，师生认证可额外领 4000 Credits。

Agent 模式和 Quest 模式有什么区别？怎么选？
Agent 模式是"边干边看"——AI 直接动手改代码，你可以随时打断和调整，适合中小型任务。Quest 模式是"先规划再执行"——AI 先出 Spec 方案，你确认后再分步执行，适合大型任务和团队协作场景。简单一句话：改几个文件用 Agent，做整个模块/项目用 Quest。
Q04
QoderWork CN 和 TraeWork Design 有什么区别？
QoderWork CN 是独立的设计工作台产品，核心理念是 "Code as Design"，提供 4 个工作台和 100+ 设计风格，产品/设计/前端都能用。TraeWork Design 是编码工具向设计侧的延伸功能，更偏向"设计稿转代码"。如果你重度依赖设计流程，QoderWork 更专业；如果只是偶尔需要设计稿，Trae 的 Design 模式够用。
Q05
企业团队怎么选型？Teams 版和 VPC 版有什么区别？
Teams 版（99 元/人/月）适合中小团队，包含 Pro+ 全部功能 + 团队管理 + 企业知识库。VPC 版（199 元/人/月）适合大型企业，增加了 VPC 专属部署、更高安全等级、定制化支持。选型建议：10 人以下先用 Pro+ 试用，10-50 人上 Teams，50 人以上或有严格合规要求选 VPC。

WorkBuddy · Chapter 04

四步上手：从登录到第一份自动交付

WorkBuddy 的上手门槛很低——不需要编程基础。四步完成你的第一次 AI 办公交付。

01
下载安装 并用微信 / 腾讯云账号登录
INSTALL · 约 3 分钟

访问 workbuddy.cn 下载桌面端，或直接使用网页版 / 小程序。微信扫码或腾讯云账号登录即可开始。体验版免费，每月 500 积分。

提示：桌面端才能获得"读写本地文件"的完整能力；纯网页端适合轻量任务。
02
配置 SkillHub 技能 与授权目录
SETUP · 按需安装

进入技能市场（SkillHub），按岗位需要安装技能。办公场景可直接选用「周报」「会议纪要」「数据汇总」等模板；垂直岗位可选用对应的领域专家。

  • 技能选择：8 万+ Skills 中挑高频场景的先装 2-3 个
  • 领域专家：100+ 专家角色，按岗位匹配
  • 目录授权：只授权必要的文件夹，避免全盘放开
  • 腾讯文档授权：打通后可读写云端文档
安全提醒：WorkBuddy 可在授权目录内读写本地文件。建议按最小必要原则授权，并定期检查授权范围。
03
第一个任务：把一份会议录音变成完整周报
FIRST TASK · 约 5 分钟

用日常语言直接下达任务，WorkBuddy 会自主拆解并分步执行：

  • "读取 D:/工作/本周会议记录 里的文件，汇总成本周项目周报"
  • "按'进展 / 风险 / 下周计划'三段式结构组织"
  • "生成一份 PPT，配色用公司蓝，输出到同目录"

它会自动完成：读取文件 → 理解内容 → 归集整理 → 生成文档与 PPT → 写回指定目录。你只需在关键节点确认。

核心心法：把"背景 + 目标 + 格式 + 输出位置"说清楚，交付质量会明显提升。模糊的需求只会得到模糊的结果。
04
进阶：沉淀技能 · 知识库 · Managed Agents
ADVANCED · 团队放大

个人效率跑通后，可以把能力放大到团队：

  • 沉淀自定义技能：把跑通的流程固化成团队可复用的 Skill
  • 企业知识库：接入腾讯文档/乐享，让 AI 基于企业资料作答
  • 统一权限管理：企业旗舰版/专享版集中管控账号与数据
  • Managed Agents：把验证过的 Agent 托管运行，开放 API 供业务系统调用
  • 信创私有化：合规要求高的企业可选择专有云部署
进阶路径：个人提效 → 团队复用技能 → 企业知识库 → Managed Agents 规模化。

WorkBuddy · Chapter 06

常见问题 FAQ

Q01
WorkBuddy 和 CodeBuddy 是什么关系？应该装哪个？
两者同属腾讯云 Buddy AI 产品矩阵。WorkBuddy 面向全员的 AI 办公工作台，主打文档、数据、PPT、自动化；CodeBuddy 面向开发者的智能编码工具，主打多文件工程、Git 管理、复杂调试。办公需求选 WorkBuddy，写代码选 CodeBuddy，两者可在同一体系内协同。
Q02
WorkBuddy 和 Trae / Qoder 有什么本质区别？
定位不同：WorkBuddy 是"办公工作台"，核心竞争力在办公协同、腾讯生态、多模态成品交付；Trae / Qoder 是"编程工具"，核心竞争力在代码生成、工程理解、Agent 自主编程。简单判断：你的任务以"文档/表格/PPT/数据"为主 → WorkBuddy；以"写代码/改工程"为主 → Trae 或 Qoder。办公岗位与全场景需求，WorkBuddy 更合适。
Q03
积分（Credits）怎么算？免费版够用吗？
WorkBuddy 体验版免费，每月 500 积分。付费版按月发放不同数量积分，用于调用高级模型或执行复杂任务。所有付费版本均包含无限次代码实时补全。个人订阅自 2026 年 7 月起分为标准版、高级版、旗舰版三档：标准版 99 元/月、高级版 199 元/月、旗舰版 999 元/月（连续包年分别为 672 / 1344 / 6720 元，年付更省）。轻度使用体验版够用，高频使用建议标准版起步。
Q04
SkillHub 是什么？和 MCP 是一回事吗？
SkillHub 是 WorkBuddy 的技能市场，收录 8 万+ AI Skills 与 100+ 领域专家，通过"技能"的方式扩展 AI 能力，支持随取随用。可以理解为面向办公场景的能力扩展体系；MCP 更偏向"连接外部工具/数据源"的协议层标准。WorkBuddy 通过 SkillHub 提供开箱即用的能力，通过腾讯生态集成提供深度连接，两者互补。
Q05
读本地文件安全吗？企业部署有哪些选择？
WorkBuddy 只在你授权的目录范围内读写本地文件，不会主动越权。但仍建议遵循最小必要原则授权，并定期检查授权范围。

企业部署有三条路径：企业旗舰版（SaaS 公有云，快速启用）、企业专享版（专有云，数据隔离）、私有化本地部署（信创环境适配，满足严格合规要求）。配合 Managed Agents 可实现智能体的统一托管与规模化运行。
